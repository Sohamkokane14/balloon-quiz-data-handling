# Pop the Right Call (data handling quiz)

A short browser game: read a workplace data-handling scenario, then pop the balloon with the right action. Wrong pops show the correct answer and the reason, and missed questions come back as a second try.

Open `index.html` in a browser, or use the GitHub Pages link. Works on laptop, tablet and phone.

Sample demo by keenmind designs. Scenarios are generic and contain no client content.
